Manifest Audit

Android Permissions & System Capabilities

Matches every permission, foreground service, hardware declaration, and intent query in AndroidManifest.xml for Marcus AI: Home Launcher v0.2.45 (Build 65, com.jchristopherfranklin.marcus).

Sensitive Permissions Intentionally Omitted:
  • READ_SMS, RECEIVE_SMS, and READ_CALL_LOG are not declared. Optional message readouts and call screening rely strictly on in-memory Notification Listener events that you enable in Android Settings.
  • ACCESS_BACKGROUND_LOCATION is not declared. Optional GPS weather checks occur only while the app is open and Offline Mode is turned off.
  • BLUETOOTH_SCAN carries android:usesPermissionFlags="neverForLocation" and is never used to infer location.
  • Optional hardware features (camera.front and camera.flash) declare android:required="false".

1. Home Launcher, App Visibility & Display

Permission / Component Activation Purpose
QUERY_ALL_PACKAGES
REQUEST_DELETE_PACKAGES		 Core Home Launcher (CATEGORY_HOME) Enumerates installed applications on your device for the App Drawer, Home shortcuts, and app-first voice launching (for example, opening Google Keep, Camera, Clock, or Spotify directly by voice), and opens Android’s uninstall confirmation dialogue when requested. Installed app lists never leave your device.
SET_WALLPAPER
SET_WALLPAPER_HINTS		 Optional user toggle Syncs Dark Grid, our geometric backdrop patterns, or your chosen custom wallpaper image to your Android home and/or lock screen via WallpaperManager when enabled.
SET_ALARM User alarm / timer action Passes voice or UI alarms and timers to Android’s built-in Clock application via ACTION_SET_ALARM and ACTION_SET_TIMER.
Manifest <queries> intents Targeted OS hand-off Grants visibility strictly to launcher apps, Bluetooth settings, system speech recognition & TTS services, Clock, Camera, default web browser, image/video viewers for Open in System Gallery, and email clients for optional bug reports.

2. HUD Gallery, Audio Player & Media Playback

Permission / Component Activation Purpose
READ_MEDIA_IMAGES (API 33+)
READ_MEDIA_VIDEO (API 33+)		 Runtime opt-in Loads device photos and videos into the HUD Gallery (hero preview, filmstrip, rotary dial scrubbing/zoom, Archive, and moving chosen items into the PIN-locked Private Folder) with strict zero autoplay.
READ_MEDIA_AUDIO (API 33+) Runtime opt-in Indexes local audio files for the offline Media Player (playlists, folder view, 5-band Equalizer, A–B looping, and sleep timer).
READ_EXTERNAL_STORAGE (maxSdkVersion="32") Runtime opt-in (Android 12 & older) Provides scoped media read access on Android 8.0–12 devices; ignored on Android 13 and above.
FOREGROUND_SERVICE
FOREGROUND_SERVICE_MEDIA_PLAYBACK
WAKE_LOCK		 While playing audio Runs MediaPlaybackService reliably in the background with Android lockscreen/notification media transport controls.
Picture-in-Picture (supportsPictureInPicture) & FileProvider Explicit user tap Floats active video in PiP only when tapped by the user; FileProvider grants scoped read access when opening an item in Android’s system gallery.
Storage Access Framework (OpenMultipleDocuments) Explicit file picker Lets you pick individual wallpapers, audio tracks, local AI models, Piper voices, or custom-ROM Wav2Vec2 ONNX files (.onnx / vocab.json) without broad storage access.
