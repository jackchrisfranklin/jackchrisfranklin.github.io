Android Permissions Disclosure (v0.2.4)

Exact permission list matching AndroidManifest.xml in Build 28 (Marcus Beta 4 / Marcus-2 4).

Permissions Excluded in v0.2.4

To keep user privacy minimal and avoid unnecessary broad media or wireless privileges, v0.2.4 removes the Photo Gallery page, Video Gallery page, and Bluetooth peer pairing/announcements completely:

  • READ_MEDIA_IMAGES — Removed (not requested)
  • READ_MEDIA_VIDEO — Removed (not requested)
  • BLUETOOTH & BLUETOOTH_CONNECT — Removed (not requested)

Core Launcher & System Permissions

Permission Required? Exact Feature Purpose
QUERY_ALL_PACKAGES
REQUEST_DELETE_PACKAGES		 Home Launcher Core Declared solely because Marcus registers as an Android CATEGORY_HOME Home Launcher so the App Drawer can list, launch, hide, search, inspect, and uninstall your installed apps on your command. App inventory never leaves the device.
SET_WALLPAPER
SET_WALLPAPER_HINTS		 Optional Action Syncs your chosen space backdrop or a custom image selected via Android’s Photo Picker (no broad media-image permission required) to the Android home/lock screen when wallpaper sync is enabled in Settings.
INTERNET
ACCESS_NETWORK_STATE		 Optional / Blocked in Offline Mode Used only when 100% Offline Privacy Mode is OFF (or when you manually download an AI model/voice, run a web search, or refresh weather).
SET_ALARM User Command Hands off alarms created by voice or the Clock applet to Android’s built-in Clock app.
FOREGROUND_SERVICE
FOREGROUND_SERVICE_MICROPHONE
FOREGROUND_SERVICE_MEDIA_PLAYBACK
WAKE_LOCK		 Active Service Only Keeps background local audio playback smooth and supports active user-triggered microphone voice capture or local recording without stalling.

Runtime Permissions (Prompted Only When Used)

Permission Default State Exact Feature Purpose
RECORD_AUDIO On Voice / Recorder Tap Used for on-device speech recognition, optional wake-word listening, and the local Voice Vault audio recorder.
READ_MEDIA_AUDIO (Android 13+)
READ_EXTERNAL_STORAGE (maxSdkVersion="32")		 On Media Audio Scan Used strictly to scan and play your local music/audio files in the Media Player page. Images and videos are not scanned.
CAMERA (optional hardware) OFF by default Requested only if you opt into On-Device Face Recognition Security in Settings and enroll/verify a face profile.
ACCESS_COARSE_LOCATION
ACCESS_FINE_LOCATION		 OFF by default Requested only if you turn on Automatic GPS Location Updates in Weather Settings. Manual city lookup requires no location permission.
READ_CONTACTS Optional Used strictly locally to resolve contact names when matching auto-read contacts or launching call/message intents by name.
POST_NOTIFICATIONS Optional (Android 13+) Displays local low-battery alerts, active media playback controls, timer reminders, and voice service notifications.
BIND_NOTIFICATION_LISTENER_SERVICE OFF by default (System Opt-in) Optional Android system setting enabling external music player controls and optional hands-free incoming call/message reading for allowlisted contacts.
